CONTROL · WHAT WE HAVE NOW

Nothing here has been touched by anybody

The screens are legible, consistent and correct, and they read like a tax form for a war. Six decisions cause that, and all six were reasonable on their own. Here are the five parts every screen is built from, and underneath each one the decision that drained it.

HEADER
Neither Guts nor Gears Round 13
The title of the game is set in the same face, at the same weight, as the word “Round”. Nothing announces itself.
A TILE
E4
A flat polygon of flat colour. It is a data cell that happens to be six-sided, not a piece of a board anyone printed.
A STAT LINE
Archmage Elara 70 / 3 / 4
A wizard’s numbers and a robot’s numbers are set identically. The deepest split in the game is invisible in its typography.
A CARD
BONUS +1 DEF to all your units Lasts the rest of the battle.
The same rounded rectangle as a panel, a tooltip and a button. Card stock is a material and this has none.
THE COMMIT
Winning the game and dismissing a dialog are the same orange pill. The biggest moment in a session has no weight on it.
A FACTION
Six factions with histories, grudges and a species war, rendered as six swatches. Colour is doing identity work alone.
