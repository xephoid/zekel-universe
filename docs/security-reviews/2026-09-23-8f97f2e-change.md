## Findings

**SEC-14-F01 (fixed): the preview page's captured views shipped in the
production build.** The dev-only route was imported statically, so a
production build emitted every captured engine view as a lazy chunk (about a
megabyte), reachable by URL though no route pointed at it. The views come
from AI-only games and hold no user data, but they are not meant to ship. Fix:
the route now loads the page through a dynamic import inside the dev-only
branch, so the production build drops the page and its fixtures. Evidence: a
production build before the fix listed 40+ fixture chunks in
`apps/web/dist/assets` and weighed 2.2 MB; after it, none, and 1.2 MB. The dev
route still loads the preview.
