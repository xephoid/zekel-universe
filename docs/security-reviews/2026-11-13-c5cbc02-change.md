## What changed

- On the game page, each screenshot is a button that opens a viewer over the
  page (`apps/web/src/pages/ShotViewer.tsx`, built on glue-kit's `Sheet`).
  Previously each was a link that opened the screenshot's address in a new
  tab.
- The viewer draws the same addresses the page already drew, as `<img src>`
  only. It changes no URL and no history.
- No new route, request, dependency, setting or stored data. No change to
  sign-in, the server or the page's security policy.
