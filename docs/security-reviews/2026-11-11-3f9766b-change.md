## What changed

- New setting `HOST` (`ServerConfig.host`): the address the server listens on.
  Empty or unset, it is `0.0.0.0` in production (the host's router must reach
  the process) and `127.0.0.1` everywhere else. When set, it wins.
- `index.ts` listens on `config.host` instead of a fixed `0.0.0.0`.
- `.env.example` lists `HOST=` empty, with a note; the README says the local
  server listens on 127.0.0.1 only.

## Observations closed

- **O1 (2026-11-11, admin layer change review) — the server binds every
  interface.** Closed by this change: outside production the server listens on
  `127.0.0.1` unless `HOST` says otherwise. Setting `HOST=0.0.0.0` locally
  (to test from a phone, say) opens it to the network again, test outbox
  included; the `.env.example` note says to do that only on a trusted network.
