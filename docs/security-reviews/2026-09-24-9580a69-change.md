## Findings

**SEC-09-F01 (fixed): the Build screen chose a platform's Core for the
player.** The engine lists a Core-needing platform once with a reserve Core
and once with a new Core bought with it when both are possible; the screen
grouped both under one item and sent whichever it listed first. Fix: the
screen asks which Core, with neither picked, and cannot go on until the
person answers; each answer sends the engine's own listed move for that way.
Test: `ngg-economy.test.tsx` presses each way on a captured robot view and
checks nothing is pre-selected, Choose stays shut until an answer, and the
sent move is the listed one for that answer.
