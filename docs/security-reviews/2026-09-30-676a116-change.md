## Observations (not new findings)

- A review server started from `apps/server/dist/index.js` listens on every
  interface (`0.0.0.0` in `apps/server/src/index.ts`), including this
  machine's public address. The last full review records this under SEC-19.
  It matters more when `E2E_TEST_OUTBOX=1` is set, since the outbox route then
  serves every mail. For this review the stack was started without the outbox
  (the spec plays as a guest). A development-only host setting would remove
  the exposure; that is a separate change.
- Engine behaviour seen on a live table, not a security matter: a rules lesson
  for tables with real cards appears at a digital table; some summaries name
  one seat two ways. Recorded in plan §18.
