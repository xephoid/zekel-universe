## Findings

### SEC-14-F01 — The rules reference names an unpublished draft rulebook

- Severity and confidence: P3, source-confirmed.
- Affected file: [docs/games/adventurer-olympics.md](../games/adventurer-olympics.md), the opening paragraph.
- Actor, preconditions, and violated boundary: any reader of the public
  repository. `CLAUDE.md` asks for no links to private documents and nothing
  about unpublished work. The cited path `port/adventurer-olympics/` is
  ignored by the engine repository's `.gitignore`, so the draft rulebook is
  not published; the doc gives its file name and location.
- Expected versus observed behavior: the doc should say its source is the
  designer's draft rulebook without a private path. It gives the path.
- Minimal reproduction: read the first paragraph of the rules doc; in the
  engine checkout, `git check-ignore -v port/adventurer-olympics` matches
  `port/`.
- Impact and affected milestones: low. Only a file name and page layout are
  revealed, no contents. None.
- Proposed fix: replace the path with "the designer's draft rulebook (not
  published)", keep the page references, and write the helper as "the
  engine's `src/core/reportHand.ts`".
- Status, owner, next action, and review date: fixed 2026-09-30 with the
  proposed wording, at the owner's go-ahead; nothing was committed before the
  fix, so the path never reached the public history.

### Question for the owner — right to publish

`CLAUDE.md` names four games as Zekel Games' own designs (Fractured Fist,
Cybernoir 2127, Warble Way Galaxy, Sweetlands Imperium). Adventurer Olympics
is not among them (nor is Neither Guts nor Gears, already in the repository).
The rules doc describes a draft by "the designer". Nothing in the repository
shows who owns the design or that it may be published under Apache 2.0. If
it is Zekel Games' own, add it to that list in `CLAUDE.md`; if it is an
outside designer's, get their permission first.

Answered 2026-09-30: the owner confirmed it is Zekel Games' own design, and it
was added to the list in `CLAUDE.md`. Neither Guts nor Gears is still missing
from that list.
