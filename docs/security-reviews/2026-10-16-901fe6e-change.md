## What changed

Each of the six Zekel Games titles now has a square cover image. The path is
a constant in the storefront data; the catalog refresh writes it into
`games.cover_image` when it inserts a game and on every later refresh, so new
and existing databases both get it. Table summaries carry the same value so
the My tables tiles can draw it. The browser renders it as an `img` `src`.
