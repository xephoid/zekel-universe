is not done here.
Release recommendation: unchanged from the full review.

## What changed

- The dev server listens on `127.0.0.1` by default instead of every interface.
  `VITE_HOST` opens it on purpose. A tunnel such as ngrok runs on the same machine
  and forwards to `127.0.0.1:5173`, so it keeps working.
- The two tunnel host names are no longer built in. `VITE_ALLOWED_HOSTS` lists any
  host names to answer to, and is empty by default.
