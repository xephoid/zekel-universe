## Findings

### SEC-07-F21 — Every seat receives every other seat's raw move, including fields the engine marks private

- Severity and confidence: P1. Reproduced on the Universe side with the
  stub engine; the private fields are source-confirmed in the engine. Not
  reproduced end to end with the real engine (random play did not reach a
  spy assignment or a battle commit).
- Affected entry point and source:
  [`apps/server/src/events.ts`](../../apps/server/src/events.ts) `toWireEvent`
  copies `engineMove` to every recipient (line 56).
  [`realtime.ts`](../../apps/server/src/realtime.ts) stores the human's
  submitted move (line 408) and the AI's `move_taken` from `run_ai_turn`
  (line 495) as `engineMove`. Both reach other seats on `table_event`, on
  the join replay, and on GET `/api/tables/:id/events`.
- Actor, preconditions, and violated boundary: any seated player at a table
  of a game whose moves carry hidden choices. In Neither Guts nor Gears the
  engine's own legal-move text for `choose_spy{hero}` says opponents never
  see it; `commit_battle_card{card}` is secret until every side commits;
  `select_extra_cards{cards}` stay secret in hand. The engine keeps its
  summaries and log free of these ("hero undisclosed"), but `run_ai_turn`
  returns the AI's full move by design (it is written for a physical table,
  where the AI's move must be read out in full). The invariant "only the
  receiving seat's engine view crosses the boundary; raw moves must also
  respect it" is broken.
- Expected versus observed: another seat should get at most a public form
  of the move. Observed (harness F21): seat 0 sent
  `{type: 'pass', hero: '<marker>'}` at a two-human table; seat 1's socket
  event and seat 1's REST replay both contained the marker.
- Minimal synthetic reproduction and side-effect assertions: two users at a
  started two-human table with the fake engine; both join over WebSocket;
  seat 0 moves with a marker field; assert the marker is absent from every
  payload seat 1 receives. Today it is present on both channels.
- Impact and affected milestones: at a human-versus-AI NGnG table the human
  can read the AI's spy carrier and any battle card it commits first; at a
  human-versus-human table each player can read the other's spy, committed
  battle card and kept extra cards before the reveal. Any later game with a
  secret move has the same hole. Cybernoir is safe only because its engine
  sends nameless AI moves; its human-to-human moves (a human Hacker's
  `report_hideout{location_name}`, a human Detective's
  `recruit_informant{target_person}`) would cross to the other human once
  two-human Cybernoir tables start (they cannot today, see R1).
- Proposed fix: stop relaying raw moves by default.
  - In `toWireEvent`, send `engineMove` only to the seat that made it; send
    other seats `null`, or only the move `type`.
  - Where a game's glue needs another seat's move for animation (Fractured
    Fist's strike reads `play_card`, Warble Way reads dice), keep a per-game
    allowlist of public move types and fields on the server, default deny;
    or ask the engine for a public form of each move (an engine change).
  - Regression test: a marker in any field of seat A's move, and in an AI
    `move_taken`, never reaches seat B on the socket or the replay.
- Status, owner, next action, and review date: open; owner to decide the
  fix; a change review with the fix; recheck by 2026-10-20.

### SEC-14-F22 — Committed docs carry local machine paths

- Severity and confidence: P3, source-confirmed (`git grep` at `b630be5`).
- Where: the "Sources" lists of `docs/games/cybernoir-2127.md` (14 lines),
  `docs/games/fractured-fist.md` (17), `docs/games/sweetlands-imperium.md`
  (19) and `docs/games/warble-way-galaxy.md` (17), added in `04961a7`
  (2026-09-15) and on `origin/main`.
- What it discloses: absolute Windows paths that include the local account
  name and the name of another local project, which CLAUDE.md forbids ("no
  local machine paths"). No credential is involved.
- Why it was missed: the 2026-09-29 sweep searched the built output and diff
  patterns for user paths but not the docs tree. This review's history
  sweep over all refs found it.
- Proposed fix: rewrite each entry as a repository-relative path or as
  "engine repository: `src/games/<game>/<file>`", and name source documents
  without their location. Removing them from history is a separate owner
  decision; the playbook does not let a review rewrite history.
- Regression check: add a local-path pattern (`[A-Za-z]:\\Users\\`,
  `/Users/<name>/`, `/home/<name>/`) to the documentation disclosure check.
- Status: open; next docs change.

### SEC-18-F23 — The MCP SDK in production has a high advisory (not reachable)

- Severity and confidence: P3, source-confirmed.
- What: `@modelcontextprotocol/sdk` 1.30.0 (through `packages/engine-client`)
  is in GHSA-6qxp-vccf-f47h: its OAuth client could send credentials to an
  authorization server chosen by the MCP server. Fixed in 1.31.0.
- Reachability: the engine client builds `StreamableHTTPClientTransport`
  with a bearer header in `requestInit` and no `authProvider`; the SDK only
  runs its OAuth flow when an `authProvider` is given. Not reachable as
  configured.
- Proposed fix: upgrade to 1.31.0 or later in its own change, and rerun the
  engine-client contract tests and a live game.
- Status: open.

### SEC-19-F24 — The server listens on every interface

- Severity and confidence: P3, reproduced (a scratch production-mode run
  reported listening on loopback, LAN and public addresses).
- Where: `apps/server/src/index.ts:51` (`host: '0.0.0.0'`, needed by the
  host platform).
- Impact: on a developer machine any local review server, including one
  started with `E2E_TEST_OUTBOX=1` (which serves every sign-in mail), is
  reachable from the network while it runs. Change reviews since 2026-09-30
  recorded this as an observation; it is now tracked as a finding.
- Proposed fix: read the bind host from config, defaulting to `127.0.0.1`
  outside production and `0.0.0.0` in production; refuse the test outbox on
  a non-loopback bind.
- Status: open.
