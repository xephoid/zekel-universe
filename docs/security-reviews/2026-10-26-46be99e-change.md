## What changed

Nothing a browser, the server or the engine can observe changed shape. The
glue modules keep the same `GlueModule` interface, now imported from
`@universe/glue-kit`; the agency rules (`submitMove`, the five triggers,
`isSubmissionAllowed`, `completesTemplate`) moved file for file with their
tests. The strike overlay is the same component in a new place, rendered by
the table page as `glue.Moment` instead of by name; the moment type the
table reads is now only `kind`, `key`, `title` and `over`, and Fractured
Fist's `StrikeMoment` adds its lanes on top. The two workspace packages are
private, version 0.0.0, and not published.
