## Fix round (2026-11-18, after Codex's review of PR #37)

Codex asked for three changes; all three are made.

1. **The clear saves at once.** Unfeature, or emptying the field, now
   calls a new route, `DELETE /api/admin/games/:id/featured`, which writes
   only `featured_rank = NULL`. The rest of a half-edited form stays
   unsaved. A failed clear shows "Not unfeatured: …" and the field gets its
   place back.
2. **Schema 9 and the first fill are all-or-nothing.** Schema 9's places
   and its version bump are one transaction. The catalog refresh writes the
   games' rows and, on an empty table, the first two places in one
   transaction. A crash part-way leaves neither, and the next start retries.
   Neither runs again once a database has rows at schema 9, so places an
   admin cleared stay cleared.
3. **The storefront spec reads the Featured state from the API** instead of
   assuming the row exists. The admin spec now checks the zero-featured
   state end to end.
