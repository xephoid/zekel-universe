- **Bricolage Grotesque** by Mathieu Triay (display headings). OFL 1.1.
- **IBM Plex Sans** and **IBM Plex Mono** by IBM (body and figures). OFL 1.1.
- **IM Fell English** by Igino Marini, from the Fell Types (the Neither Guts nor

## Generated images

The 25 Cybernoir 2127 character portraits in `docs/games/cybernoir-2127/`, and
the face crops made from them in `docs/design/cybernoir-rain-neon/assets/faces/`,
were generated by the project owner with the **DreamShaper 8** model run locally
in ComfyUI. DreamShaper 8 is released under the **CreativeML Open RAIL-M**
license. That license claims no rights in the images a user generates and
allows them to be used and shared, subject to the use restrictions in its
Attachment A, which continue to apply to anyone who uses these images. Images
made purely by a model are probably not protected by copyright, so this project
claims none in them beyond any human-made changes. No other model, LoRA or
upscaler was used; record any that are added later here.
